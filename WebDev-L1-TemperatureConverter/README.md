# Temperature Converter Website

## OIBSIP Internship

This project was developed as part of the **OASIS INFOBYTE Internship Program** under the **Web Development & Designing** track.

### Task

**Level 1 - Task 3: Temperature Converter Website**

## Project Description

The Temperature Converter is an interactive web application that converts temperature values between Celsius, Fahrenheit, and Kelvin.

The application accepts a numeric temperature value, allows the user to select the input unit, and displays the equivalent values in all three temperature units.

## Features

- Numeric temperature input
- Celsius input option
- Fahrenheit input option
- Kelvin input option
- Celsius to Fahrenheit conversion
- Celsius to Kelvin conversion
- Fahrenheit to Celsius conversion
- Fahrenheit to Kelvin conversion
- Kelvin to Celsius conversion
- Kelvin to Fahrenheit conversion
- Input validation
- Error message for invalid input
- Absolute-zero validation
- Clear conversion result display
- Responsive design
- Mobile-friendly interface
- Clean and centered user interface
- Smooth navigation

## Technologies Used
