# NovaTech - Landing Page

## OIBSIP Internship

This project was developed as part of the **OASIS INFOBYTE Internship Program** under the **Web Development & Designing** track.

### Task

**Level 1 - Task 1: Landing Page**

## Project Description

NovaTech is a modern, responsive landing page designed for a fictional technology brand.

The website focuses on clean design, responsive layout, clear navigation, and a simple user experience.

## Features

- Responsive navigation bar
- Hero section with headline and call-to-action
- Features section
- About section
- Contact/footer section
- Responsive design for desktop, tablet, and mobile
- Hover effects
- Smooth scrolling navigation
- Modern typography and consistent colour scheme

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- CSS Flexbox
- CSS Grid
- Responsive Media Queries
